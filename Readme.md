## ✨ Features

- **Multi-Page Architecture**: Dedicated pages for Home, Projects, About, Résumé, and Contact.
- **Editorial Typography**: Styled with classical **Times New Roman** and balanced letter-spacing.
- **Smart Sticky Header**: Centered navigation tabs with auto-hide on scroll-down and a glassmorphic blurred backdrop on scroll-up.
- **Dynamic Scroll Animations**: Smooth `IntersectionObserver` reveal animations for sections, project cards, and content blocks.
- **Interactive Resume Download Feedback**: Tactile download simulation with progress spinner and confirmation state before delivering `resume.pdf`.
- **Ambient Floating Mesh**: Soft, warm background glow blobs that drift organically in the background without cluttering content.
- **Interactive Project Filtering**: Instant category filtering (AI, Real-time Systems, Analytics, Machine Learning, E-Commerce) with smooth scale and opacity transitions.
- **Accessibility & Performance**: Built with pure HTML5, CSS3, and JavaScript — zero external frameworks or bulky dependencies required, with full `prefers-reduced-motion` support.

## 🚀 Local Development

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nidhyyy/Portfolio.git
   cd Portfolio
   ```
2. **Open the project**:
   - Simply open `index.html` in any web browser, or
   - Use the **VS Code Live Server** extension (`Right-click index.html` > `Open with Live Server`).

No `npm install` or server configuration is required.
